# RK3576 飞镖视觉 开机自启动

上电后自动运行 `build/Camera/show --window`，显示识别画面。由 systemd 管理，崩溃或相机未就绪会自动重试。

## 部署文件

| 文件 | 作用 |
|---|---|
| `deploy/dart-vision.service` | systemd 单元，装到 `/etc/systemd/system/` |
| `tools/wait_hik_camera.sh` | 启动前最多等 30s 让海康相机（USB `2bdf:`）枚举 |
| `tools/run_rk3576.sh` | 板端启动器（设置项目内 MVS 库路径、传 `--config`） |

## 安装（板端，一次即可）

```bash
sudo cp deploy/dart-vision.service /etc/systemd/system/
sudo chmod +x tools/wait_hik_camera.sh
sudo systemctl daemon-reload
sudo systemctl enable dart-vision.service
sudo systemctl start dart-vision.service
```

## 常用命令

```bash
systemctl status dart-vision.service          # 状态
sudo journalctl -u dart-vision.service -f      # 实时日志（含 [STATS]）
sudo systemctl restart dart-vision.service     # 重启程序
sudo systemctl stop dart-vision.service        # 临时停止
sudo systemctl disable dart-vision.service     # 取消开机自启
```

## 关键设计

- **运行身份** `Tronlong`：需要 `video` / `plugdev` 组访问相机；root 跑反而拿不到桌面授权。
- **DISPLAY=:0 + XAUTHORITY**：板子桌面自动登录到 `:0`，窗口才能显示。
- **ExecStartPre 等相机**：上电时 USB 枚举比系统慢，先等相机出现再启动，避免首次失败。
- **Restart=always + StartLimitIntervalSec=0**：程序退出（相机掉线、崩溃）5s 后自动重拉，不设重试上限。
- **stdbuf -oL**：`std::cout` 接管道默认块缓冲，加它才能实时看到 `[STATS]`。
- **启动器用 `tools/run_rk3576.sh`**，不要用 `run.sh`（那是 WSL 专用，库路径指向 `/opt/MVS`）。

## 验证方法

```bash
# 重启后确认
systemctl is-active dart-vision.service
pgrep -af build/Camera/show
DISPLAY=:0 XAUTHORITY=/home/Tronlong/.Xauthority xwininfo -root -tree | grep -i hikrobot
sudo journalctl -u dart-vision.service -b -n 20 --no-pager | grep STATS
```

正常时 `[STATS]` 持续输出，`detect_ms` 约 10~25ms；抓到绿灯时 `lost` 会随丢失变化，否则为 0 表示视野内无目标。

## 注意

- 日志里的 `libGL error: failed to load driver: rockchip` 是板端 GL 驱动缺失的告警，窗口仍能显示（软件渲染），不影响识别。
- 串口默认 `enable_serial: 0`；接电控并确认 USB-TTL 后改成 1，`serial_port: /dev/ttyUSB0`。
- 若改了程序或配置需要重新编译：`sudo systemctl stop dart-vision.service && bash tools/run_rk3576.sh --rebuild --window` 验证后再 start。
