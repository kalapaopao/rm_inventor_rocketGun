# 镖架水平像素偏差通信协议

> ⚠️ **本文描述的是已废弃的 v0 8 字节帧（`FF … 0D`），代码已不再实现。**
> 现行协议为定长 6 字节 `A5 | TARGET | int16 YAW | CRC16`，见
> [串口通讯协议_电控对接.md](串口通讯协议_电控对接.md)（对接版）与
> [串口通讯协议_v1.md](串口通讯协议_v1.md)（内部设计稿）。
> 本文仅作历史记录保留。

本次替换此前未联调的20字节坐标帧。不要再使用旧接收程序解码。
只实现视觉到电控 TX；不擅自增加发射指令、接收状态机或机械动作。

## 来源和取舍

已阅读 [Misaka21/dart serial_thread.cpp](https://github.com/Misaka21/dart/blob/main/hardware/serial/serial_thread.cpp)、
[fixed_packet.hpp](https://github.com/Misaka21/dart/blob/main/hardware/serial/fixed_packet.hpp) 和
[detector.cpp](https://github.com/Misaka21/dart/blob/main/detector/detector.cpp)。
独立实现相同的8字节打包格式，不复制对方消息总线/线程框架；保持当前单进程与独立发送线程。
参考发送的是当前像素偏差，而非光轴角、绝对电机角或预测坐标。
参考帧没有CRC/序号/有效标志，为保持线格式不占用保留字节。
这是兼容性取舍，不代表适合直接驱动发射机构；物理电控联调尚未完成。

## 数据定义

`yaw_offset_px = round(当前卡尔曼灯心x - (原图宽度/2整数中心 + yaw_aim_offset_px))`

- 右正左负，单位：原图像素；使用精调灯心，不是模型框中心，也不是显示窗口缩放坐标。
- 四舍五入后饱和到 int16 范围 [-32768,32767]。
- 默认瞄准偏移为0，即图像中心十字；不使用标定主点作为准心。
- 不发送5秒预测值；预测仍可在画面上观察，内参视线角仍保留于结果结构中。
- 只有已确认、当前帧有观测且结果年龄不超过 `serial_max_age_ms` 时才发送。
- 丢目标、推理失败导致结果过期、NaN、无结果时停发，绝不以零伪装有效目标。
- 真正对准时会发送有效0，故**下位机必须区分“没收到包”和“收到偏差0”**。

## 线格式

115200 baud，8N1，无流控；默认每50ms发一次最新有效值。

| 字节偏移 | 内容 |
|---|---|
| 0 | 0xFF帧头 |
| 1..2 | int16_t yaw_offset_px，小端补码 |
| 3..6 | 固定0保留位 |
| 7 | 0x0D帧尾 |

示例：+123为 `FF 7B 00 00 00 00 00 0D`；-123为 `FF 85 FF 00 00 00 00 0D`；
有效零为 `FF 00 00 00 00 00 00 0D`。
接收端按8字节长度解析，不要以第一个0D为分隔符（数值本身可能含0D）。
帧头/帧尾或保留位不符时按字节滑动重新同步；端口应专用，避免混入日志。
此格式不能可靠检出所有比特损坏；若有安全要求，应双方协商升级到带CRC和序号的版本。

## 保护和显示

发送线程非阻塞写，处理短写/EINTR/EAGAIN；50ms内未写完则停止发送，避免半帧与下一帧拼接。
停止等待可中断，不因大周期拖慢退出。真实断线需要检查接线后重新启动程序，不自动重连设备。
当前默认有效期500ms是初始调试值，需要根据实测推理延迟收紧；**MCU还必须有独立接收超时**，
超时应退出视觉控制/停止跟随，不能永久沿用最后一个偏差，更不能据此自动发射。

左上角显示同一个 `selectYaw()` 算出的 `yaw_offset_px`，无效为N/A；
另显示 `Serial OFF/ON/STOPPED`、最近成功write的 `last TX yaw_px`、完整写包数与错误数。
`last TX`是操作系统成功写入，不是下位机ACK；停发后仍显示历史值，不能当作当前有效命令。
串口默认关闭时也显示待发参数，方便无需电控即可调试。录像包含该面板。

## 启用与验证

在 `Camera/camera_config.yaml` 中配置（不要直接照抄未知设备路径）：

```yaml
vision:
  enable_serial: 0         # 对接电控且确认超时保护后才改为1
  serial_port: ""         # 改为实际WSL/Linux串口路径
  serial_baud: 115200
  serial_period_ms: 50
  serial_max_age_ms: 500
  yaw_aim_offset_px: 0.0
```

`cmake --build build -j2` 后执行 `ctest --test-dir build/Vision --output-on-failure`。
新增PTY测试验证真实串口系统调用路径和8字节编码、正负/零、饱和、过期/丢目标停发、状态与退出。
只连接虚拟PTY，不控制真实电机。尚未验证物理USB串口、电控解码、机械方向与真实相机绿灯表现。
回退需同时恢复旧SerialOutput、Camera配置接线、像素偏差生成与显示；
不要单独回退帧编码而保留新下位机解码，避免协议错配。
